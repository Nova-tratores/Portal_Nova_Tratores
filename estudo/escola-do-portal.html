Desresumindo o código

O portal parece "resumido" porque usa atalhos do JavaScript. Aqui você aprende os 7 atalhos que mais aparecem. Faça as estações na ordem; cada uma marca sozinha quando você termina.

    TypeScript é JavaScript com etiquetas

    O portal é escrito em TypeScript. Ele é JavaScript com etiquetas de tipo, como : number. Apague as etiquetas e sobra JavaScript normal:

    // TypeScript (como está no portal)
const brl = (v: number) => v.toLocaleString('pt-BR')

// JavaScript (igual, sem a etiqueta)
const brl = (v) => v.toLocaleString('pt-BR')

    Então, na hora de LER o portal: ignore tudo que vem depois de dois-pontos dentro dos parênteses, e ignore as linhas type e interface.

    Os 7 atalhos

    ResumidoQuer dizer
    (x) => x * 2uma função: function (x) { return x * 2 }
    lista.map(...)lista nova, trocando cada item
    lista.filter(...)lista nova, só com quem passa no teste
    lista.reduce(...)junta a lista num valor só (quase sempre soma)
    a || 'padrão'se a for vazio ou zero, usa 'padrão'
    obj?.nomepega nome só se obj existir, sem dar erro
    cond ? x : yum if/else numa linha

    Onde isso está no portal

    Abra no VS Code o arquivo src/lib/requisicoes/itens-compra.ts. Ele é a regra da tela Requisições → nova requisição → "O que vai comprar?": soma o total e monta o texto das observações. Usa os 7 atalhos. Se um dia o total sair errado nessa tela, é nesse arquivo que você mexe.

    O básico da programação

    A sintaxe do JavaScript do zero: o que é cada sinal, por que se escreve assim e como era no Java. Em cada tópico tem um código que você pode mudar e rodar na hora.
